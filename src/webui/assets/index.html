Connecting…

The SD card on your computer

The card opens as a network drive in your computer's own file manager: copy disk images, ROMs and files to it and from it as with any folder. The shared folder is the Mac II's SD Card disk.

http://…/sd/
  1. Open File Explorer, right-click This PC and choose Map network drive…
  2. Pick a letter, enter http://…/sd/ as the folder and click Finish.
  3. With a web UI PIN set, Windows only asks for it over HTTPS: leave the PIN off, or see the User Guide.
  1. In the Finder, choose Go ▸ Connect to Server… (⌘K).
  2. Enter http://…/sd/ and click Connect; as a guest when there is no PIN.
  3. Files copied keep their type, creator and resource fork on the Mac II's SD Card disk.
  1. In Files, choose Other Locations, and under Connect to Server enter dav://…/sd/
  2. Or with rclone, davfs2 or any WebDAV client: http://…/sd/

Don't change a disk image while the Mac is using it: eject it, or switch the Mac to another first. ·
